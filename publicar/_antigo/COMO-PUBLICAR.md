# Como publicar os Algoritmos TEV no GitHub Pages

Endereço final previsto: https://tiagojgcc.github.io/tev/
(o nome do repositório define o fim do endereço; se escolher outro nome, o QR code tem de ser refeito)

## 1. Criar o repositório (2 minutos)
1. Entrar em https://github.com/new
2. Repository name: `tev`
3. Public (obrigatório para o GitHub Pages gratuito)
4. Marcar "Add a README file" e carregar em "Create repository"

## 2. Carregar os ficheiros
1. No repositório, carregar em "Add file" > "Upload files"
2. Arrastar os três ficheiros desta pasta: `index.html`, `tev-na-pratica.html`, `tev-consulta.html`
3. "Commit changes"

## 3. Ligar o GitHub Pages
1. Settings > Pages (menu da esquerda)
2. Em "Build and deployment": Source = "Deploy from a branch"; Branch = `main`, pasta `/ (root)`; Save
3. Esperar 1 a 2 minutos e abrir https://tiagojgcc.github.io/tev/

## 4. Atualizar mais tarde
Repetir o passo 2 com os ficheiros novos (o mesmo nome substitui o anterior). O endereço e o QR code não mudam.
